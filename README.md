## The Disaster   -- English

1.20.1 Forge version only.
Future support for 1.21.1 and Neoforge is planned...

This is a brief explanation of The Disaster Mod, which is currently under development.

It will add several bosses and armor to the Overworld, Nether, and End.

Please note that it is not designed to be played in conjunction with cheat mods (such as ManaitaPlus, ClickManaita, ManaitaMTK, etc.).
